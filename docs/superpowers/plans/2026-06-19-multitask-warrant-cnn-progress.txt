2026-06-19 — T01 + T02 done (bundled because the PRD pairs each rule module
with its unit test suite under "Testing decisions"):

  Added:
    - server/warrant_rules.py
        IntersectionMeta dataclass (major_lanes, minor_lanes,
        posted_speed_kph, is_signalized, n_approaches).
        Helpers: _hourly_volumes (96-slot → 24-hour reduction),
        _major_minor_axes (volume-based NS-vs-EW axis assignment),
        _speed_factor (0.70 if posted_speed_kph ≤ 40, MUTCD §4C.01).
        MUTCD threshold tables for Table 4C-1 Conditions A and B as
        lane-count-keyed dicts.
        evaluate_w1 — eight-hour vehicular volume (Cond A OR Cond B,
        ≥ 8 qualifying hours, confidence = hours/8).
        evaluate_w2 — four-hour vehicular volume, piecewise-linear fit
        to Figure 4C-1 with minor-lane-dependent floor + intercept.
        evaluate_w3 — peak-hour curve ~150 vph above W2.
        evaluate_w4 — pedestrian volume (4-hour ≥ 107 OR 1-hour ≥ 133),
        low-speed factor applied to both thresholds.
        evaluate_all_mutcd — aggregate API returning
        {warrant_name: (met, confidence)}.

    - tests/test_warrant_rules.py
        20 pure-function tests covering helpers + each warrant's
        triggered / not-triggered / low-speed / lane-count behaviour
        + aggregate API. All 20 pass (verified locally on Python 3.12).

  Decisions:
    - File placed in server/ (next to local_warrants.py) rather than
      server/ml/ — these are rule evaluators, not ML code, and they
      mirror the existing W-Local 1/2/3 module's layout.
    - flow_matrix convention chosen: (5, 96), channels-first, with
      channel 4 = pedestrian crossing volume. Matches PRD §Implementation
      Decisions / Algorithmic centerpiece / Inputs.
    - Each slot value is treated as a PCU/hr rate (matching the existing
      synthetic-traffic generator's slot semantics from the parent plan);
      hourly volume = mean of 4 slot rates.
    - Figure 4C-1 and 4C-3 are encoded as piecewise-linear fits with
      lane-dependent floor/intercept rather than as digitized lookup
      tables, to keep the module dependency-free. Methods chapter will
      cite the figures and document the fit constants.

  Next: T03 (intervention_rules.py — assign_intervention_label).
